### Umbera is a private messenger built on one rule: the server should never know who talks to whom.

- **No phone number, no email** — sign up with a username only.
- **Post-quantum end-to-end encryption** — X25519 + ML-KEM (Kyber), signatures with ML-DSA (Dilithium).
- **Sealed sender** and rotating mailbox addresses — the server can't link sender and recipient.
- **Encrypted voice and video calls**, groups and file sharing. Optional Tor.
- **iOS and Android**, with a free trial.
